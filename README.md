# Fazenda Ferrier

Site institucional em capítulos — editorial, didático e enxuto.

Não é uma galeria. Cada rota ensina um ofício do campo (terra, pecuária, granja, lavoura) e assina a Fazenda Ferrier.

## Rotas

- `/` início
- `/historia`
- `/terra`
- `/rebanho`
- `/granja`
- `/producao`
- `/origem`

## Stack

React, TypeScript, Vite, Tailwind, GSAP, Lenis, React Router.

```bash
npm install
npm run dev
```
